# Examples

This folder contains a collection of example notebooks that are **not actively maintained**.
The first code cell of each notebook states the `feos` version that it was last run with, e.g.,

```python
# feos version: 0.9.6
```

If a notebook does not work with the latest version of `feos`, you can install the version stated in the notebook, e.g., `pip install feos==0.9.6`.

The tutorials and recipes in the [documentation](https://feos-org.github.io/feos/) are kept up to date with the latest release.
Their notebooks are located in the [`docs/tutorials`](../docs/tutorials) and [`docs/recipes`](../docs/recipes) folders.
